## Publication checklist for a small future batch

1. Establish distinct intent and utility against published pages and draft counterparts.
2. Correct conflicting title, description, scene, medium, taxonomy and reference instructions.
3. Supply concise expected-result, reference-input, usage, customization, failure-check and limitation guidance that helps users rather than padding word count.
4. Obtain an authorized accurate preview through included access only. Keep personal references private, preserve old assets and never substitute a source reference for a result.
5. Review applicable adult identity consistency, prompt-driven age/expression, child exclusions, distinct multi-person handling, anatomy, dimensions and mobile crops. No unapproved bulk generation.
6. Record truthful provenance: “suggested tool” is not tested compatibility. Do not guarantee identity or product fidelity.
7. Validate server-rendered explanations, metadata, image/entity associations, sitemap eligibility, contextual links and useful hub membership.
8. Reconcile exact production records, back up changes and release only accepted records after local checks. Existing consent and Auto ads release dependencies remain.
9. Verify live results before reconsidering AdSense. Increasing page count alone does not resolve low-value content.
