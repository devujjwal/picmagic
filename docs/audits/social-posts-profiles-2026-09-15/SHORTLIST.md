## Collection decision

Reuse `/collections/instagram-profile-picture` (currently inactive), preserving its slug and using clearer cross-app display copy such as “Profile Picture / DP Ideas”. Rework its existing rain draft rather than duplicate it. Keep the existing utility members available for later editorial selection; do not delete them. There is no existing dedicated post collection, so propose `/collections/instagram-post-ideas`. It would curate existing canonical owners plus the two approved new posts. Do not create one collection per messaging app. `creative-transformations` remains an optional secondary membership only. All memberships/activation are proposals, not production changes.

Use current `tags`, `collections`, `aspect_ratio`, `image_brief`, `prompt_text`, editorial fields and `reference_contract` before adding model fields. Intended use can be expressed in tags/collection membership for this small batch. Artistic contracts need palette-aware preservation; single-person proposals have one identity and one depiction. Profile variants must retain their separate square composition; no multi-panel display hint.
