# Poster editor font

Noto Sans Devanagari variable font (width/weight axes), downloaded 10 October 2026
from the official Google Fonts repository:

https://github.com/google/fonts/tree/main/ofl/notosansdevanagari

Local asset: `noto-sans-devanagari.ttf`.
License: SIL Open Font License 1.1, retained in `OFL-NotoSansDevanagari.txt`.
No font-service request is needed in the editor. English and Hindi text is drawn
with this local font; it does not change the site's existing branding fonts.
